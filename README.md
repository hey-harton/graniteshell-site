# 🐚 Granite Shell

Granite Shell adalah aplikasi web berbasis **Ruby on Rails** dengan integrasi **TailwindCSS** yang berfungsi sebagai penyedia layanan terminal CLI berbasis web.  
Melalui Granite Shell, pengguna dapat mengakses **IBM Granite** di platform **Replicate** secara langsung dari browser dengan antarmuka yang sederhana, aman, dan responsif.

---

## ✨ Fitur Utama

- 🚀 **Web‑based CLI**: Jalankan perintah langsung dari browser tanpa perlu setup lokal.
- 🔗 **Integrasi IBM Granite (Replicate)**: Akses model Granite dengan API Replicate.
- 🎨 **UI modern dengan TailwindCSS**: Tampilan clean, responsif, dan mudah dikustomisasi.
- 🔒 **Cloudflare Turnstile Ready**: Proteksi anti‑bot untuk keamanan akses.
- ⚙️ **Rails Convention Over Configuration**: Struktur kode yang rapi dan scalable.

---

## 🛠️ Teknologi yang Digunakan

- **Ruby on Rails** → Backend utama, RESTful API, session & auth.
- **TailwindCSS** → Styling modern dan utility‑first.
- **Replicate API** → Integrasi dengan IBM Granite.
- **Cloudflare Turnstile** → Anti‑bot verification.
- **PostgreSQL** → Database default (bisa diganti sesuai kebutuhan).
